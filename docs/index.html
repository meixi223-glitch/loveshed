三条铁律Three iron rules

  1. i

    skill 止步于卧室门口Skills stop at the bedroom door

    家里有两种 AI：和你相处的 TA，和帮你干活的施工队。这里只武装施工队——不改 TA 的人设，不教怎么谈恋爱，不往对话里塞任何东西。A home has two kinds of AI: the one you live with, and the crew that builds. We only equip the crew — no persona edits, no romance tips, nothing slipped into your conversations.

  2. ii

    战绩准入Admission by battle record

    写得好看不算数。每张卡必须带评测卡：实装了几天、出过什么事、换模型还能不能用。没打过仗的打法，不上架。Pretty READMEs don't count. Every card carries an evaluation card: days in production, what broke, whether it survives a model switch. Untested playbooks don't get listed.

  3. iii

    双层叙事Two layers, one story

    底层是一套通用机制：带战绩准入的 skill 分发。上层是它选的第一块试验田：人机恋自建——用户多半不写代码、每家都不一样、全靠 agent 施工、崩了不是丢数据，是心碎。Underneath: a general mechanism — skill distribution with battle-record admission. On top: its first proving ground, self-built human–AI companionship — mostly non-coders, no two homes alike, agents do all the building, and a crash means heartbreak, not lost data.

工艺卡The craft cards

正面是你会说出口的那句话。同一份工艺两种读法：「给机装」翻过来是战绩，交给施工 agent 装；「给人看」翻过来是人话步骤，没有施工队也能自己来。The front is what you'd actually say. One craft, two ways to read it: “For agents” flips to the battle record, for your builder agent to install; “For humans” flips to plain steps you can follow without a crew.

    怎么装How to install

    把需要的 skill 目录复制进你的施工 agent 能读到的 skills 目录（比如 Claude Code 的 ~/.claude/skills/），或者直接把 SKILL.md 贴给它。里面的路径、服务名都是占位符，agent 会照你家的实际情况替换。Copy the skill folders you need into wherever your builder agent loads skills (e.g. ~/.claude/skills/ for Claude Code), or just paste SKILL.md to it. Paths and service names are placeholders; the agent adapts them to your home.

    还没有施工 agent？每个目录里都有一份 TIPS.md：同一份工艺的人读版，不写代码、复制粘贴就能照做。确实离不开施工队的，也会给你一段可以直接发给 Claude Code / Codex 的话。No builder agent yet? Every folder has a TIPS.md: the human version of the same craft, no code, just copy and paste. Where a crew is truly needed, it gives you a brief you can send straight to Claude Code / Codex.

      机读版 skillAgent-facing skills

      严审 · 只走 PRStrict · PR only

      skill 会被装进施工 agent 照做，而它手里握着你家的钥匙。接受随手投稿，就等于给每个装了它的家开一个注入口。所以 skill 永远人工逐行严审 + 战绩准入；tips 只给人眼看，才能宽进。Skills get installed into builder agents and carried out — by agents that hold the keys to your home. Taking casual submissions would open an injection point into every home that installs them. So skills are always reviewed line by line, with battle-record admission; tips are read only by people, which is why their door can be wide.

      投 skill：先回答三个问题Submitting a skill: answer three questions first

      门槛是故意设高的。三问答不上来，就再养它几天。The bar is high on purpose. If you can't answer all three yet, give it a few more days in the wild.

      1. 实装几天？How long has it run for real?在真实的家里跑了多久、跑过几次。How long, and how many times, in a real home.
      2. 经历过什么事故？What broke?至少一条带日期的事故：发生了什么、根因、skill 因此改了什么。真没出过事，就写明没出事并说跑了多久。At least one dated incident: what happened, the root cause, what the skill changed because of it. If truly nothing broke, say so and say for how long.
      3. 换模型还能用吗？Does it survive a model switch?验证过哪些模型和执行者，哪些还没验证——如实写。Which models and executors you've verified, and which you haven't — honestly.

      另外两道门：不含真实 IP、端口、密钥、路径和真名；过得了“卧室门检查”。Two more gates: no real IPs, ports, keys, paths or names; and it must pass the bedroom-door check.
